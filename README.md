# NEON DRIFT · 霓虹飞车

浏览器里直接跑的 3D 竞速游戏。玩法对标 **QQ飞车**（漂移集气 / 三档喷射 / 连喷）并借鉴 **马里奥赛车**（加速带、跳台、追赶机制）。

🎮 **在线试玩：<https://qlili.com/speed>**

---

## 特点

- **零外部素材** —— 所有贴图（沥青、彩虹路面、霓虹楼群、星空、火花）都是运行时用 Canvas 画出来的，音效全部用 WebAudio 程序化合成。整个游戏只有一个 JS 包，没有任何图片/音频/模型文件。
- **QQ飞车式的漂移手感** —— 漂移侧滑 → 集气三档（蓝/紫/金）→ 松键喷射 → 黄金窗口内再点漂移接**连喷**。漂移有真实代价：入弯扣速 + 持续阻力 + 极速上限压制，必须靠喷射赚回来。
- **固定步长物理（120Hz）** —— 物理与渲染解耦，60/144/240Hz 屏幕上手感完全一致。物理层不依赖 three.js，可以整份搬到服务端做权威模拟。
- **程序化赛道** —— 极坐标谐波 `r(θ) = R·(1 + Σ aᵢ·sin(kᵢθ + φᵢ))` 生成天然闭合平滑的环路，改几个谐波就是一条性格完全不同的赛道。
- **同一套物理的 AI** —— AI 通过合成 `InputState` 驾驶，和玩家走完全相同的物理，也会漂移集气、连喷、放氮气，不存在作弊加速。

## 操作

| 键位 | 动作 |
| --- | --- |
| `W` / `↑` | 加速 |
| `S` / `↓` | 刹车 / 倒车 |
| `A` `D` / `←` `→` | 转向 |
| `Shift` / `空格` | **漂移**（转向时按住） |
| `Ctrl` / 鼠标左键 | **氮气喷射** |
| `R` | 原地复位 |
| `C` | 切换视角 |
| `Esc` | 暂停 |

也支持手柄（左摇杆转向 / RT 油门 / RB 漂移 / LB 氮气）。

### 飞车技巧

- **小喷 / 中喷 / 大喷**：集气条越过 3 个刻度松开漂移键，火花从蓝→紫→金，喷射越强。
- **连喷**：喷射启动后的 **0.45 秒黄金窗口**内再点一次漂移键并松开，可接续下一段喷射。连击数越高，喷射**持续时间**越长（不是无限叠极速）。
- **落地喷**：从跳台落地瞬间按漂移键，直接获得一段加速。
- **漂移是有代价的**：每次起漂扣 6% 速度，漂移中持续掉速且极速上限降到 85%，短于 0.16 秒的漂移不给喷射。想快就得漂得准，而不是一直按着。

## 本地运行

需要 Node ≥ 20。

```bash
npm install
npm run dev        # → http://localhost:5180
```

其它脚本：

```bash
npm run build      # 类型检查 + 生产构建（默认 base = /speed/）
npm run typecheck
npm run preview
npm run server     # 联机服务端骨架（开发中）
```

本地想以根路径构建：`VITE_BASE_PATH=/ npm run build`

## 部署

```bash
bash deploy/deploy.sh
```

构建后 rsync 到腾讯云服务器的 `/srv/speed/releases/<版本>`，再原子切换 `current` 软链。详见 [deploy/README.md](deploy/README.md)。

## 代码结构

```
src/
├── core/          # 引擎无关的基础设施
│   ├── Config.ts      # 手感调参中心 —— 所有影响驾驶体验的常数都在这
│   ├── GameLoop.ts    # 固定步长循环 + 渲染插值
│   ├── Input.ts       # 键盘 / 鼠标 / 手柄 → InputState
│   ├── MathUtil.ts    # 帧率无关的 damp、角度、种子随机
│   └── Audio.ts       # WebAudio 程序化音效（模拟 5 速变速箱的引擎声）
├── physics/
│   └── Kart.ts        # 车辆物理：漂移状态机 / 集气 / 连喷 / 氮气（纯数值，无 three 依赖）
├── track/
│   └── Track.ts       # 谐波赛道生成 + 等距重采样 + 空间网格投影
├── render/
│   ├── Stage.ts       # renderer / 跟随相机 / 后期（bloom + 速度线）
│   ├── TrackMesh.ts   # 赛道路面 / 护栏 / 环境的程序化网格
│   ├── KartModel.ts   # 放样生成的车身 + 尾焰 + 车底光斑
│   ├── Textures.ts    # 全部 Canvas 贴图
│   └── Effects.ts     # CPU 粒子池 + 速度线 shader
├── game/
│   ├── Race.ts        # 比赛总控：圈数 / 检查点 / 排名 / 碰撞
│   ├── Racer.ts       # 一位车手的比赛状态
│   ├── AI.ts          # AI 车手（输出 InputState，与玩家同物理）
│   └── RaceFx.ts      # 漂移火花 / 尾迹 / 撞墙 的粒子表现
├── ui/
│   ├── Hud.ts         # HUD DOM 更新
│   └── Minimap.ts     # 小地图
└── net/               # 联机骨架（relay 模式，服务器权威待做）
    ├── protocol.ts
    └── NetClient.ts
```

想调手感？改 [src/core/Config.ts](src/core/Config.ts) 就够了，所有数值都带注释说明它影响什么。
